# exp-20260810-001：web_book 按 Reasonix 8 模式重构（渲染器去重 + 契约 + 配置 + 版本号）

## 标签
`前端` `重构` `Reasonix` `markdown` `契约` `配置` `版本号`

## 触发条件
维护 web_book 前端双端渲染、修改 `server.py` API 路由、或部署流程时，先查本条经验。

## 关键信息 / 根因
- **渲染器重复**：原 Markdown 渲染器在 `js/app.js` 与 `js/reader.js` 重复实现（逻辑等价、仅占位符/块组装风格不同），一处修 Bug 另一处常漏改 → 收敛到 `js/markdown.js`（`window.MarkdownRenderer`），`render(text, emptyHtml)` 支持两端各自的空占位符。
- **硬编码**：`server.py` 端口/规则名 → 收敛 `config.py`；前端存储 key/API → 收敛 `js/config.js`（`window.APP_CONFIG`）。
- **无契约**：API 路由前后端无权威契约 → 新增 `TOOL_CONTRACT.md` + `scripts/contract-check.mjs` 双向校验。
- **版本号手动改易漏**：前端 `?v=` → `scripts/bump-version.mjs` 自动打时间戳，`publish.bat` 部署前调用。

## 改动
- [`js/markdown.js`](js/markdown.js) — 新增共享渲染器（源自 app.js 较完整版 + 可配置空占位符参数）
- [`js/config.js`](js/config.js) — 新增前端配置（STORAGE_KEY / THEME_KEY / API 端点）
- [`config.py`](config.py) — 新增后端配置（PORT / FIREWALL_RULE_NAME / BASE_DIR / DATA_FILE）
- [`server.py`](server.py) — 顶部改 `from config import BASE_DIR, DATA_FILE, PORT, FIREWALL_RULE_NAME`；`rule_name` 改用配置
- [`js/app.js`](js/app.js) — 删除内嵌 MarkdownRenderer 类，改用 `window.MarkdownRenderer`；常量改解构 `window.APP_CONFIG`；调用点传 `preview-placeholder`
- [`js/reader.js`](js/reader.js) — 同上去重；调用点传 `empty` 占位符
- [`index.html`](index.html) / [`reader.html`](reader.html) — 前置引入 `js/config.js` + `js/markdown.js`
- [`TOOL_CONTRACT.md`](TOOL_CONTRACT.md) — 新增 API 契约（唯一权威）
- [`scripts/contract-check.mjs`](scripts/contract-check.mjs) — 契约双向校验
- [`scripts/bump-version.mjs`](scripts/bump-version.mjs) — 版本号自动化
- [`publish.bat`](publish.bat) — 部署前接入版本号更新 + 契约校验
- [`README.md`](README.md) — 更新结构树与技术要点

## 验证
- `node --check js/app.js js/reader.js js/markdown.js js/config.js` → 语法通过
- `python -m py_compile server.py config.py` → 通过
- `node scripts/contract-check.mjs` → 契约一致（server: /api/novel, /api/info, /api/chapter）
- `node scripts/bump-version.mjs` → 更新 `?v=` 成功
- 浏览器回归：写作端保存/预览 + 阅读端渲染应正常（双端行为保持不变）
