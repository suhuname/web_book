# UI 主题切换与阅读体验优化

## 日期
2026-07-26

## 修改摘要
为写书工具添加了三套主题切换功能（暗夜/护眼绿/纸墨），并优化了整体阅读体验。主题系统基于 CSS 变量实现，切换时平滑过渡，用户选择会持久化到 localStorage。

## 涉及文件
- `index.html` — 在工具栏右侧新增主题切换按钮组
- `css/style.css` — 重构 CSS 变量为主题驱动系统，新增三套主题定义，优化字体/间距/颜色
- `js/app.js` — 新增 ThemeManager 类，在 App 构造函数中初始化主题

## 关键决策
1. **CSS 变量驱动主题**：使用 `[data-theme]` 属性选择器定义三套主题变量，通过修改 `document.documentElement` 的 `data-theme` 属性实现一键切换，无需重新加载页面。
2. **护眼绿主题**：采用低饱和度的绿色系（`#e8f5e9` / `#dcedc8` 等），降低蓝光刺激，适合长时间写作。
3. **阅读体验优化**：
   - 编辑器和预览区行高从 1.6/1.8 提升至 1.9
   - 预览内容最大宽度从 800px 微调至 820px，字号从 16px 提升至 17px
   - 增加字间距 `letter-spacing: 0.3px` 提升中文可读性
   - 编辑器与预览区内边距从 `20px 24px` 增加至 `24px 32px`
4. **硬编码颜色迁移**：将 `.preview-content strong`/`em`/`code` 中的硬编码颜色值提取为 CSS 变量（`--strong-color`/`--em-color`/`--code-color`），确保各主题下显示一致。

## 注意事项
- 主题按钮使用 emoji 图标（🌙/🌿/📄），若需更专业的图标可替换为 SVG
- 新增主题时只需在 `css/style.css` 中添加 `[data-theme="xxx"]` 变量块，并在 `js/app.js` 的 `ThemeManager.themes` 和 `themeNames` 中注册即可
- `localStorage` 键 `write_book_theme` 用于持久化主题选择，清除浏览器数据后会恢复默认暗夜主题
