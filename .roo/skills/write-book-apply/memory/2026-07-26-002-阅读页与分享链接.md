# 阅读页与分享链接

## 日期
2026-07-26

## 修改摘要
新增纯阅读界面 `reader.html`（供读者使用），并在编辑器工具栏加入「🔗 分享」按钮。点击分享后将小说全部内容（书籍元信息+所有章节）编码为 base64url 嵌入 URL hash，复制到剪贴板；其他用户通过该链接访问 `reader.html` 即可离线解码阅读，无需后端服务。

## 涉及文件
- `reader.html` — 新增，阅读页（顶栏+正文+上下章翻页+目录抽屉+主题切换）
- `js/reader.js` — 新增，阅读页逻辑（URL 数据解码、Markdown 渲染、章节导航、主题切换、键盘左右翻页）
- `index.html` — 工具栏新增 `#btnShare` 分享按钮
- `js/app.js` — `App` 新增 `_shareBook()` 与 `_fallbackCopy()`；`_bindCoreEvents()` 中绑定分享事件

## 关键决策
1. **无后端分享方案**：将 JSON 数据 → UTF-8 bytes → base64 → base64url 编码后拼入 `reader.html?ch=<id>#d=<data>`。利用 hash 不发送到服务器的特性，数据仅在客户端解码，纯前端可运行。
2. **编码实现**：`TextEncoder` 处理 UTF-8 中文，避免 `btoa` 直接处理中文报错；base64url 替换 `+/=` 保证 URL 安全。
3. **降级兼容**：剪贴板优先 `navigator.clipboard.writeText`，失败降级 `execCommand('copy')`；阅读页无 hash 数据时回退到 `window.__NOVEL_DATA__` 本地数据。
4. **阅读页体验**：默认护眼绿主题、字号 18px、行高 2、居中 820px 栏宽；右下浮动目录按钮、左右方向键翻页、`?ch=` 参数定位章节、`history.replaceState` 无刷新翻页。
5. **代码复用**：阅读页内嵌简化版 `MarkdownRenderer`，与编辑器渲染规则保持一致，避免修改 `app.js` 的类结构。

## 注意事项
- 分享链接长度受浏览器 URL 限制（通常数 MB），章节内容极大时链接会很长；后续如需更短链接可引入 LZ-String 压缩。
- `reader.html` 与 `index.html` 共用 `css/style.css` 的主题变量（`data-theme`），阅读页通过内联 `<style>` 覆盖阅读专属排版。
- 阅读页 body 允许滚动（覆盖全局 `overflow:hidden`）。
- 其他设备访问需通过同一 HTTP 服务（当前 `python -m http.server 8080`）提供 `reader.html` 页面；hash 中的数据不依赖服务器。
