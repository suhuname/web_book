# 添加刷新按钮 — 从 JSON 文件重新拉取章节内容

## 日期
2026-07-27

## 修改摘要
在编辑器工具栏新增「🔄 刷新」按钮，点击后从 `data/chapters/*.json` 重新拉取所有章节的最新内容并更新编辑器 UI，方便用户在其他工具修改 JSON 后即时获取最新内容。

## 关键决策
1. **先保存再刷新** — `_refreshFromJson()` 首先调用 `_saveCurrentChapter()` 保存当前编辑内容，确保编辑不丢失
2. **并行拉取** — 使用 `Promise.all` 并行 fetch 所有章节 JSON，提升刷新速度
3. **差异检测** — 对比新旧内容的 `content` 和 `title`，仅在有实际变化时更新 UI
4. **UI 反馈** — 按钮显示「⏳ 刷新中...」→「✅ 已刷新 N 章」/「✅ 已是最新」/「❌ 刷新失败」，2 秒后恢复原状
5. **向后兼容** — 不修改数据存储结构，不影响 localStorage 数据格式

## 注意事项
- 刷新时按钮禁用，避免重复点击
- 若 JSON 文件不存在或请求失败，对应章节保持原有内容不变
- 刷新后会自动更新预览模式（如果在预览模式下）
