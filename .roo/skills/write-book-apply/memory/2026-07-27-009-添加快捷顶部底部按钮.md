# 添加快捷到顶部/到底部按钮

## 日期
2026-07-27

## 修改摘要
为编辑页（index.html）和阅读页（reader.html）添加浮动快捷按钮组，支持一键滚动到页面顶部或底部。

## 涉及文件
- [`css/style.css`](css/style.css:876) — 将原有 `.back-to-top` 样式重构为 `.back-to-top` + `.back-to-bottom` 共享样式组
- [`index.html`](index.html:108) — 添加 `#backToBottom` 按钮，改用内部元素滚动（因 html/body 有 `overflow:hidden`）
- [`reader.html`](reader.html:81) — 添加 `#backToBottom2` 按钮，使用 `window.scrollTo()`

## 关键决策
1. **按钮布局**：使用 `position: fixed` 垂直堆叠，`↑`（回到顶部）在底部（`bottom: 28px`），`↓`（跳到底部）在其上方（`bottom: 80px`），间距 52px。
2. **显示逻辑**：
   - `↑` 按钮：滚动距离 > 300px 时显示
   - `↓` 按钮：滚动距离 > 300px 且 **不在底部 100px 范围内** 时显示（到底部后自动隐藏）
3. **编辑页（`index.html`）滚动策略**：由于 [`css/style.css:78-81`](css/style.css:78) 设置 `html, body { overflow: hidden }`，文档窗口无法滚动。因此：
   - **编辑模式**：滚动 `<textarea#editor>`（`overflow-y: auto`）
   - **预览模式**：滚动 `.preview-panel`（`overflow-y: auto`）
   - 通过 `_getScrollBox()` 函数根据 `display` 状态检测当前可见面板
   - 滚动监听直接绑定到 `#editor` 和 `#previewPanel` 的 `scroll` 事件
   - 模式切换按钮（编辑/预览）点击后延迟 60ms 刷新按钮状态
4. **阅读页（`reader.html`）滚动策略**：覆盖了 `html,body{overflow:auto}`，故直接使用 `window.scrollTo()`。
5. **样式复用**：将 `.back-to-top` 和 `.back-to-bottom` 的公共样式提取为群组选择器，减少代码重复。各自通过独立的选择器设置不同的 `bottom` 值。

## 注意事项
- 编辑页的按钮状态依赖于内部元素的 scroll 事件，而非 window scroll 事件
- 模式切换后需要延迟刷新按钮状态，因为切换动画需要时间生效
- 底部 100px 判定阈值（`el.scrollHeight - 100`）可根据内容密度微调
- 两个按钮的 ID 在 index.html 中为 `backToTop` / `backToBottom`，在 reader.html 中为 `backToTop2` / `backToBottom2`，避免与现有脚本冲突
