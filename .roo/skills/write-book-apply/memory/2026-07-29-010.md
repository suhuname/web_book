# 文本中插入图片功能

## 日期
2026-07-29

## 修改摘要
为写书工具增加完整的图片插入功能，支持三种插入方式：上传本地图片（转 base64 嵌入）、输入图片 URL、从剪贴板粘贴图片、拖拽图片到编辑器。

## 涉及文件
- [`index.html`](../../../../index.html) — 添加工具栏「🖼️ 图片」按钮、隐藏 file input 和图片插入弹窗
- [`js/app.js`](../../../../js/app.js) — 添加图片插入的全部逻辑方法
- [`css/style.css`](../../../../css/style.css) — 添加图片弹窗标签样式、预览样式、编辑器图片样式

## 关键决策
1. **本地图片转 base64 嵌入**：由于是纯前端应用，上传的图片通过 FileReader 转为 base64 data URL 后，以标准 Markdown 图片语法 `![描述](data:image/...)` 插入到文本内容中，与现有的 Markdown 渲染器完全兼容
2. **弹窗双标签设计**：上传图片和 URL 链接两种模式通过标签切换，符合用户直觉
3. **剪贴板粘贴支持**：拦截编辑器的 paste 事件，检测到剪贴板中有图片数据时自动读取并插入
4. **拖拽支持**：拦截编辑器的 dragover/drop 事件，支持从桌面或浏览器拖拽图片到编辑区
5. **图片大小限制 10MB**：防止过大的 base64 数据导致 localStorage 存储超出容量限制

## 注意事项
- base64 编码的图片会存储在章节内容的 Markdown 文本中，并通过 localStorage 持久化。大图片可能导致存储占用显著增加。建议使用 1MB 以下的图片
- 预览渲染完全复用现有的 `MarkdownRenderer` 类（已支持 `![alt](url)` 语法，第 287 行），无需修改渲染逻辑
- 如需移除图片，只需在编辑器中删除对应的 Markdown 图片语法即可
