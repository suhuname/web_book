# 一键删除章节图片按钮

## 日期
2026-07-31

## 修改摘要
在工具栏新增「🗑️ 删图」按钮，点击后可一键删除当前章节中所有 Markdown 图片语法（`![desc](url)`）。

## 涉及文件
- `index.html` — 新增按钮 DOM，更新 CSS/JS 缓存版本号
- `css/style.css` — 新增 `.btn-remove-images` 样式（红色主题）
- `js/app.js` — 新增 `_removeAllImagesFromChapter()` 方法，绑定按钮点击事件

## 关键决策
1. **按钮位置**：放在「🖼️ 图片」按钮之后、「📥 导出」按钮之前，与图片功能形成对应
2. **删除逻辑**：使用正则 `!\[([^\]]*)\]\(([^)]+)\)` 匹配 Markdown 图片语法，同时清理前后多余空行
3. **二次确认**：先统计图片数量，通过 `confirm()` 弹窗确认后才执行删除，避免误操作
4. **零图保护**：如果当前章节没有图片，点击按钮会提示「当前章节中没有图片」
5. **缓存版本号**：同步更新到 `20260731-1`，确保浏览器加载最新资源

## 注意事项
- 仅删除 Markdown 图片语法，不影响其他 Markdown 格式（粗体、链接等）
- base64 内嵌图片和外部 URL 图片都会被删除
- 删除后自动触发保存和统计更新
