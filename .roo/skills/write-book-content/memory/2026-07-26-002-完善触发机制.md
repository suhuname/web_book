# 完善技能触发机制

- **日期**：2026-07-26
- **类型**：技能优化
- **涉及文件**：[`SKILL.md`](SKILL.md)

---

## 修改内容

### 1. 触发条件大幅扩展

| 优化项 | 之前 | 之后 |
|-------|------|------|
| 隐式触发类型 | 4 类 | **8 类** |
| 触发关键词总数 | 约 15 个 | **约 60 个** |
| 可用模式 | `code`, `ask` | `code`, `ask`, `architect` |

### 2. 新增的触发类型

| 触发类型 | 覆盖关键词 |
|---------|-----------|
| **大纲管理** | 修改大纲、调整大纲、更新大纲、写大纲、改大纲、重新规划剧情等 |
| **扩写/缩减** | 扩写、缩减、补充细节、丰富内容、精简等 |
| **剧情调整** | 改剧情、调整情节、冲突调整、情感线调整等 |
| **人物/设定** | 改人设、修改角色、人物关系、改设定等 |
| **整体操作** | 写小说、写书、创作内容、改书、编辑小说等 |

### 3. description 字段更新

```
之前：小说内容创作 — 根据大纲《星落之城》撰写章节正文...
之后：小说内容创作 — 根据大纲《星落之城》撰写/扩写/续写/修改章节正文、调整大纲、修改情节、调整人物设定...
```

新增 `architect` 模式支持，允许在设计剧情走向时使用架构模式。

---

## 效果

现在当用户说出以下任意表述时，都能触发本技能：
- 「**修改大纲**」「调整大纲」「重新规划剧情」
- 「**改内容**」「改章节」「改小说」
- 「**修改情节**」「改情节」「调整冲突」
- 「**改人设**」「修改角色」「调整人物设定」
- 「**写到哪了**」「当前进度」「写作状态」
