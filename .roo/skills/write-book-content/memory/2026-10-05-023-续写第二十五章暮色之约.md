## 剧情摘要

紧接 ch_24 同一日暮色（榕树街车边）。

- **开篇**：暮色下沉，她手机上还亮着顾母发来的黑白旧照。顾深第一句问的是"她没为难你吧"——他今天一整天都紧，"那种紧，不像替自己紧，是替他母亲紧"。她把手机递过去，他看了很久："这张照片，我没见过。"
- **发展**：她把顾母那句话原样念出来——"以后他要是让你受委屈，你直接跟我说。"他没动，然后整个人松开了："这句话，我妈从来没跟我说过。她只会说'你别回来哭'。"
- **高潮**：暮色里用力的拥抱；耳边"你知不知道你有多厉害"／她"我知道，我刚刚知道了"。
- **温情**：两人沿榕树街慢慢走，糖水摊上两碗冰绿豆沙、竹凳还是烫的；她讲自己在厨房门口进退不得的那两分钟；他说母亲当年一边看店一边做饭、手上有伤从不说疼——"她这辈子，什么都是自己来的"；她说"你妈妈跟你有点像""都不说"。上车后："她那个人，软话一句都不会说，就只会用最硬的壳，把最软的东西包起来"；他讲这三年"我妈每年问我一次回不回去，我爸一辈子没问过我什么，我掉在中间，回哪个头都是欠的"——"今天好像谁都不欠了"。
- **收尾**：回到住处，冻饺子进冷冻格；苏漫语音轰炸，她只发三行字（"汤很好。""她给我包了饺子。""她说以后有人欺负我，让我直接找她。"），对面回"林晚，你这是嫁进去了"。**她终于展开钱包里那张纸条**——"一九九三年。我用自己赚的第一笔钱买的。戴了三十年，现在给你。别怕，日子是一天一天撑出来的。"她读了两遍，按原折痕折回。
- **【钩子】** 夜里十一点四十，顾深来电，背景是办公室的开关声与椅子拖动声："我现在得回公司一趟。"周明在更远处："顾总，是最大的那个客户——他要解约。"

## 关键决策

1. **按作者要求，纸条在本章揭晓**：内容定为顾母自己写的传家话——"一九九三年。我用自己赚的第一笔钱买的。戴了三十年，现在给你。别怕，日子是一天一天撑出来的。"**理由**：金镯是顾母**自己赚的第一笔钱**买的，才能与她"一个人撑起来"的人设同频；同时避免与后续"玉镯＝他奶奶留下的"（大纲 ch_31）撞道具。
2. **用"这张照片，我没见过"加重照片的份量**：母亲藏了几十年的照片，第一次给的是儿媳，不写煽情，只写他没见过的反应。
3. **称呼线索**：ch_24 已由顾母口头化解，本章不再重复，只在苏漫对话里用"你这是嫁进去了"轻轻点一下。
4. **章末不写"她的那颗星终于落在身边"式总结**（原大纲【收尾】表述），改为具体物件（冻饺子、纸条、楼道灯）＋钩子收尾。
