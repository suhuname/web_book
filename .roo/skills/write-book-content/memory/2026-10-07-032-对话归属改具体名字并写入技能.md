# 对话归属规则：一律写具体名字，禁止「他说／她说」（ch_32/ch_33 已改写，规则写入技能）

**日期**：2026-10-07
**章节**：ch_32《第三十二章 夜里的那盏灯》、ch_33《第三十三章 怕黑的人》
**字数统计**：ch_32 2022 → **2155 字**；ch_33 2066 → **2165 字**（改名后同时补足了短句问答的归属）

## 背景（作者要求）

> "章节里面的他说和她说都改成具体的名字，这样读起来需要转一下才知道是谁说的，写到技能里面，后面也要注意这点。"

作者读 ch_32/ch_33 时发现：对话提示语写"他说""她说"，读者要回头数行才能判断说话人——尤其在三人同场（ch_33 顾母＋顾深＋林晚）和短句问答（"嗯。""我知道。""什么。"）时最明显。

## 关键决策

1. **改写范围**：ch_32、ch_33 全文的对话提示语（含间接引用）改为具体姓名——"顾深说""林晚说""林晚问""顾母说""顾母问""周明说""沈瑶说"等，**"他说／她说／他问／她问"零残留**（脚本校验通过）。
2. **短句问答补归属**：原先无提示语的短句也补上说话人，例如
   - `"什么。"` → `"什么。"顾深问。`
   - `"为什么。"` → `"为什么。"顾深问。`
   - `"有什么。"` → `"有什么。"顾母问。`
   - `"说什么。"` → `"说什么。"顾深问。`
   - `"嗯。"` → `"嗯。"顾深应了一声。`／`"嗯。"顾母说。`
3. **旁白里的主语也写名字**：涉及同一场多人时，把"她／他"换成姓名，避免"她换了鞋""她把信封收进布袋"这类需要数行的指代（如"顾母换了鞋""林晚开始收拾长桌""顾深把碗往前推了推"）。
4. **规则写入技能**：在 [`.roo/skills/write-book-content/SKILL.md`](../SKILL.md) 的"### 对话格式规范 ⚠️ 重点注意"下新增**第 6 条**——对话归属必须写具体名字、禁止"他说／她说"，附对照表（两人对话／三人同场／短句问答三种场景），并注明 ch_32/ch_33 已落地、**此后所有新章节同样执行**。
