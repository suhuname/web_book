## 做法（可复用的四步）

1. **扫描过滤**（临时脚本）：按 `---` 把每章切成场景；提示语正则
   `(?<=[，。！？：；"”\n ]|^)(他|她)((?:又|才|先|接着|忽然|低声|轻声|小声)?(?:说|问|答(?!应)|补充|解释|开口))(?=[，。：；！？"”…]|了|\n|$)`
   ——动词后必须紧跟标点/“了”/行尾，借此排除 **"她说不清""他说得对""他说的明明是""她说话的时候""她说完又笑了笑""对他说"** 这类叙述用法。初扫 254 处 → 去噪后 **139 处真提示语**。
2. **说话人判定**：
   - 场景内"提到过的"人物按 **他／她** 性别过滤；只剩一个 → 高置信（H）自动改；
   - 场景里出现 **"那个男人／客户／甲方／负责人／老板／房东／司机…"** 等未具名角色且位于上一次具名提示语之后 → **降级为人工**（这条护栏正是为了拦住"甲方负责人说'行，往下做'"被误判成顾深）；
   - **引号内的"她说"**（转述别人话）标记 Q，不动。
3. **人工逐条核对**：脚本输出"上一句对话 + 上一位具名说话人 + 建议"，我逐条确认后写成映射表（`ch_23: {"10": "甲方负责人"}` …），脚本只把"他/她"这**一个字**换成姓名，保证不动其他文字。

## 关键决策

1. **不碰叙述句**：只有"提示语"才算，凡"说"后接 得/的/话/不/完/着 一律视为叙述，不改。
2. **不碰引号内转述**：那是人物原话，改了等于改台词。
