## 剧情摘要

### 第十四章 风雨考验
顾深母亲突然到访广州，与林晚见面后以冷淡的态度明确表达了对这段关系的不满。饭桌上顾母全程没有问林晚任何问题，用无声的隔离语言让林晚感受到阶级差距。林晚回家后搜索顾母的背景，发现对方是年营收过亿的文化集团掌舵人，陷入深深的自卑。苏漫打来电话痛骂她"被盛远PUA太久了"，沈瑶在茶水间用"别辜负他的眼神"点醒她。傍晚顾深坦白与母亲大吵一架，两人在楼下相拥，林晚主动吻了他。

### 第十五章 坚定选择
林晚振作后主动接下公司最棘手的项目，连续两周加班到深夜。沈瑶嘴硬心软地陪她改方案。提案当天，林晚以专业表现征服了挑剔的甲方。顾深当场宣布她为星澜文化合伙人。顾母再次约见林晚，这一次林晚带着作品集和获奖证明，不卑不亢地为自己正名。顾母翻完作品集后虽然没有明说同意，但让顾深送她回家——这已是顾母能给出的最大让步。

### 第十六章 山雨欲来
成为合伙人后林晚发现公司财务状况堪忧。程昱暗中挖走星澜文化最大的三个客户，公司账上资金只剩一个月。顾深四处融资碰壁——程昱在背后给所有投资人打了招呼，切断了一切注资渠道。林晚和顾深在办公室里彻夜相拥，面对即将到来的黑暗。最后一位投资人也拒绝注资后，顾深握着林晚的手说了一声"对不起"。

### 第十七章 从零开始
星澜文化正式清算，四人搬到老居民楼的出租屋里重新开始。他们接街边奶茶店、淘宝详情页等小单子维生。顾深开始学记账，为省快递费自己骑电动车送货。苏漫带着小龙虾和啤酒来看大家，四个人在小小的客厅里碰杯："敬它还没死。"靠着过硬的设计质量口碑慢慢传开，订单开始增多。结尾顾深画出新的品牌概念，林晚告诉他"一定用得上"。夕阳中他握着她的手说："虽然人少了，但好像比以前更好了。"

## 关键决策
1. 顾母的性格设计为"克制而疏离的体面"，不说重话但每一个表情都扎人，比直接辱骂更有力量
2. 林晚在第十五章中的成长弧线：从被动接受到主动证明，完成了人物弧光的闭合
3. 公司破产后选择"温馨重组"而非"苦情沉沦"，苏漫带夜宵的桥段为沉重的第四幕注入暖色
4. 第十七章结尾呼应全书的"星光"意象——"星星落下来了，但它们没有熄灭"
