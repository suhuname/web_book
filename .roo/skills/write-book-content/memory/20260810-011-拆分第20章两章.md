## 剧情摘要
- **ch_20 坚定选择**：林晚接下新锐科技品牌全套视觉项目，通宵改稿，沈瑶放下敌意帮忙。提案成功，顾深当众宣布她为星澜文化合伙人。团队与苏漫祝贺。章末收到顾母再次约见的陌生号码消息，林晚决定不躲不逃。
- **ch_21 无声的让步**：赴约前夜林晚翻遍五年作品集，苏漫语音鼓励。她穿拿奖那天的连衣裙赴约，主动开口自我介绍、坦诚身份与成就，把作品集与获奖文档摊开在顾母面前。顾母一页页翻过，目光从审视松动为重新评估。最后只说"让顾深送你回家吧"——顾母能给出的最大让步。
- **ch_22 暮色之约**：走出餐厅，广州暮色温柔。顾深在楼下等了两小时，见她平安出来，紧绷的肩膀终于放松。那句"你妈说让你送我回家"让他露出从未有过的如释重负的笑。他用力的拥抱、耳边那句"你知不知道你有多厉害"，她回"我知道，我刚刚知道了"。车内坦诚、车停楼下道别，回家后苏漫祝贺。她想起「星落之城」——她的星终于落在身边。

## 关键决策
- 用户要求将"第二次见顾母"与"走出餐厅"分别单独成章，均写细腻感情。
- 第20章保留"新项目+提案+合伙人宣布+团队庆祝"，以顾母约见消息作为章末悬念收尾。
- 第21章专注顾母的松动；第22章专注顾深与林晚的浓烈感情。
- 用 insert-chapter.js 连续插入两章，自动重编号 ch_21→ch_23 起的所有章节。
- 手动补充了 insert-chapter.js 未处理的：outline.md 详细剧情、novel.js 的 manifest 同步（insert 未更新 novel.js，需重新生成）、chapters 文件与 novel.json 的 summary 同步。
